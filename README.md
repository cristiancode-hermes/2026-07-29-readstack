# ReadStack

Seguimiento de lectura y gestión de libros — construido con Angular 22 + NestJS 11.

## Características

- Gestión de libros con CRUD completo
- Seguimiento de estado de lectura (leyendo, completado, pendiente, abandonado)
- Registro de sesiones de lectura con páginas y tiempo
- Metas de lectura personalizadas
- Dashboard con estadísticas y progreso
- Reseñas y valoraciones de libros
- Autenticación JWT
- Totalmente responsive

## Stack

- **Frontend:** Angular 22, TypeScript, Tailwind CSS, RxJS
- **Backend:** NestJS 11, TypeScript, SQLite, TypeORM
- **Autenticación:** JWT
